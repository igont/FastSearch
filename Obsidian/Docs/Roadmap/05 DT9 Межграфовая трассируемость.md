# DT9. Межграфовая трассируемость

[← Roadmap](<00 Roadmap.md>)

## Producer

DT9 связывает document graph DT5 и accepted code semantics DT8. Explicit links работают без embedding provider; semantic candidates требуют qualified model DT5/DT8.

## Наблюдаемый результат

FastSearch показывает, какие code nodes реализуют или проверяются конкретным TDR/document и какие documents могут быть затронуты code change. Verified relations отделены от candidates, каждый impact path объясним.

## Новые возможности

- Cross edges DOCUMENTS, GOVERNED_BY, DECIDED_BY, IMPLEMENTS, VERIFIED_BY, CONTRADICTS.
- Explicit IDs/links and imported `.fastsearch/knowledge/curated` verified relations.
- Semantic candidate links from node descriptions.
- Candidate accept/reject/change-kind review commit.
- Independent link revision and stale causes.
- Docs→code and code→docs impact queries.
- Verified/candidate/unresolved path separation.
- Supersession/conflict/cycle handling.
- Benchmark минимум 50 verified links and 20 controlled changes.

## Внутренние slices

1. Cross-edge schema and explicit resolver.
2. Semantic candidate generator/explanation.
3. Review queue/commit and `.fastsearch/knowledge/curated` export.
4. Impact traversal and path explanation.
5. Supersession/conflict/cycle semantics.
6. Link quality benchmark.

## Не входит

- Автоматическое изменение кода после TDR change.
- Automatic authored document rewrite.
- Verified status только по similarity score.
- Dtree orchestration implementation.

## Exit gate

- Explicit IDs produce deterministic high-confidence edges.
- Semantic candidates never appear in verified-only query before review.
- Known dataset meets selected precision/recall threshold.
- Document/code changes produce expected explained impact set.
- Superseded/removed targets make links stale/conflicting rather than silently retargeted.
- `.fastsearch/knowledge/curated` round-trip preserves verified links and provenance.
