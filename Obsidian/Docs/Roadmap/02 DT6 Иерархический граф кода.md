# DT6. Иерархический граф кода

Этап заменён FastGraph FG3. [Передача графового контура](<../FastGraph.md>) объясняет новую последовательность. DT6 сохраняется как исторический паспорт FastSearch.

[← Roadmap](<00 Roadmap.md>)

## Producer

DT6 использует graph storage/revision foundation DT5 и current Rust/Python symbol extractor DT3. Каждый language adapter получает отдельный capability matrix и acceptance.

## Наблюдаемый результат

FastSearch строит hierarchy repository/module/namespace/type/class/function/test и resolved directed relations. Форматирование, комментарии и перестановка declarations внутри неизменившегося scope не меняют symbol ID.

## Новые возможности

- Stable symbol key без absolute path и start byte.
- Normalized AST, symbol table, imports и language resolver.
- Nodes package/module/namespace/class/struct/trait/function/method/test.
- Edges CONTAINS, IMPORTS, CALLS, IMPLEMENTS, INHERITS, READS, WRITES, PROVIDES, CONSUMES, TESTS.
- Incoming/outgoing indexes без duplicated reverse edges.
- Exact, inferred и unresolved confidence.
- Per-language declarations/hierarchy/imports/calls/types/inheritance/tests status.
- Controlled fixtures reformat/reorder/body/signature/call changes.

## Внутренние slices

1. Stable key/domain migration.
2. Rust hierarchy/import/call resolver.
3. Python hierarchy/import/call resolver с честным dynamic coverage.
4. Relation storage/indexes.
5. Additional-language adapter contract без обещания implementation.
6. Identity/relation benchmark.

## Не входит

- Automatic cross-module function move tracking.
- Compiler-perfect dynamic/reflection references.
- Semantic descriptions и stale propagation.
- Documentation links.

## Exit gate

- Reformat/reorder within scope сохраняют IDs.
- Body-only update сохраняет node и меняет revision/hash.
- Rename/signature/module move допускают removed+added без ложной migration.
- Rust/Python known edges match expected dataset; unresolved cases не становятся exact.
- Parser failure одного языка даёт partial graph без потери других languages.
- Current source locator/get behavior сохраняется либо мигрируется явно.
