# DT7. Ревизии и причинная актуальность

Этап заменён FastGraph FG4. [Передача графового контура](<../FastGraph.md>) объясняет новую последовательность. DT7 сохраняется как исторический паспорт FastSearch.

[← Roadmap](<00 Roadmap.md>)

## Producer

DT7 требует document graph DT5 и code graph DT6. Он не генерирует semantic descriptions; он создаёт state/review foundation для них.

## Наблюдаемый результат

Каждый scan создаёт immutable observed graph revision. FastSearch показывает новые, удалённые, обновлённые и stale relations, объясняет root cause и не порождает ложный cascade при локальном implementation-only change.

## Новые возможности

- Observed и accepted revisions.
- Edge dimensions presence/delta/semantic state/confidence/cause.
- Derived node summary по incident edges.
- Change levels L0 formatting, L1 implementation, L2 behavior, L3 contract, L4 architecture.
- Root ChangeEvents и lazy affected sets.
- SCC condensation для cycles.
- Scope verdicts local_only, bounded_to, propagate_to_callers, architectural_review_required.
- Atomic review commit exact scope/revision.
- Tombstones и multi-root-cause tracking.

## Внутренние slices

1. Revision/event schema and migrations.
2. Structural graph diff.
3. AST-based initial change classification.
4. Causal propagation/SCC.
5. Review queue/commit.
6. Controlled 20-change benchmark и false-cascade metrics.

## Не входит

- Model summaries и `.fastsearch/knowledge/curated` export.
- Automatic Codex launch.
- Semantic candidate links.
- Массовое физическое stamping stale на все reachable edges.

## Exit gate

- Added/removed/current relation diff соответствует fixtures.
- L0 не меняет semantic state; L1 не создаёт downstream stale cascade.
- L3/L4 создают объяснимый affected path до configured boundaries.
- Closing local root event снимает только производные states этого cause.
- Concurrent stale review commit отклоняется.
- Cycles terminate deterministically; node summaries воспроизводимы.
- Controlled experiment измеряет false/missed invalidations.
