# Карта покрытия обсуждения

[← Traceability](<00 Traceability.md>)

## Ownership

| Тезис | Фиксация | Состояние |
|---|---|---|
| FastSearch владеет рабочими областями, поиском и снимками источников; FastGraph владеет графом знаний; dtree владеет оркестрацией агентов. | [FastGraph](<../FastGraph.md>), [TDR-FS-3](<../TDR/TDR-FS-3 Поставщик снимков источников.md>) | Принято |
| Репозиторий источника владеет кодом, авторской документацией и `.fastsearch/workspace.toml`; переносимое принятое графовое знание находится в `.fastgraph/knowledge/curated`. | [FastGraph](<../FastGraph.md>), [PAR-FS-009](<../../Paradigms/Архитектура/Сопровождение графа/04 Переносимый namespace .fastsearch.md>) | Принято |
| Существующие `.cfmap.md` и графовые каталоги `.fastsearch` являются переходными данными прежнего решения, а не новым контрактом FastSearch. | [FastGraph](<../FastGraph.md>), [TDR-FS-2.2](<../TDR/TDR-FS-2.2 Namespace .fastsearch и migration.md>) | Требует управляемого переноса |
| `.cfknowledge`, внешний корень сервиса и корневой `.search` являются прежними схемами размещения; FastSearch не расширяет их как графовое хранилище. | [PAR-FS-009](<../../Paradigms/Архитектура/Сопровождение графа/04 Переносимый namespace .fastsearch.md>), [TDR-FS-2.2](<../TDR/TDR-FS-2.2 Namespace .fastsearch и migration.md>) | Принято |

## Workspaces и sources

| Тезис | Фиксация | Состояние |
|---|---|---|
| Один системный FastSearch executable обслуживает каталог известных рабочих областей; executable не копируется в каждый repository. | [PAR-FS-011](<../../Paradigms/Архитектура/Рабочие области и интерфейс/01 Рабочая область и два контура источников.md>), [TDR-FS-2.1](<../TDR/TDR-FS-2.1 Каталог и admission рабочей области.md>) | Принято; implementation gap |
| Workspace содержит ровно два optional contours: documentation и code; каждый допускает несколько roots. | [PAR-FS-011](<../../Paradigms/Архитектура/Рабочие области и интерфейс/01 Рабочая область и два контура источников.md>), [TDR-FS-2.1](<../TDR/TDR-FS-2.1 Каталог и admission рабочей области.md>) | Принято; implementation gap |
| Корни документации и кода объединяются в соответствующие поисковые пространства FastSearch; FastGraph получает их через версионированный снимок источников. | [PAR-FS-011](<../../Paradigms/Архитектура/Рабочие области и интерфейс/01 Рабочая область и два контура источников.md>), [TDR-FS-3](<../TDR/TDR-FS-3 Поставщик снимков источников.md>) | Принято; результат DT12 |
| Ноль contours означает incomplete workspace; один contour полностью работоспособен независимо от другого. | [PAR-FS-011](<../../Paradigms/Архитектура/Рабочие области и интерфейс/01 Рабочая область и два контура источников.md>) | Принято; implementation gap |

## Terminal UX

| Тезис | Фиксация | Состояние |
|---|---|---|
| Startup открывает известную область по current directory либо показывает recent-workspace picker; новая область принимает один root. | [PAR-FS-012](<../../Paradigms/Архитектура/Рабочие области и интерфейс/02 Terminal-first интерфейс.md>), [TDR-FS-2.3](<../TDR/TDR-FS-2.3 Terminal routing и terminal-dialogue.md>) | Принято; implementation gap |
| Service/index/model paths не входят в basic onboarding; discovery предлагает roots двух contours с возможностью пропустить каждый. | [PAR-FS-012](<../../Paradigms/Архитектура/Рабочие области и интерфейс/02 Terminal-first интерфейс.md>), [Нормативные шаблоны](<../UX/01 Нормативные шаблоны интерфейса.md>) | Принято; implementation gap |
| Human chrome полностью принадлежит terminal-dialogue; FastSearch передаёт typed content и transitions. | [PAR-FS-012](<../../Paradigms/Архитектура/Рабочие области и интерфейс/02 Terminal-first интерфейс.md>), [TDR-FS-2.3](<../TDR/TDR-FS-2.3 Terminal routing и terminal-dialogue.md>) | Принято; visual baseline частично реализован |
| Search является первым полезным действием готовой области; result actions локальны, full rebuild не скрывается внутри query. | [PAR-FS-012](<../../Paradigms/Архитектура/Рабочие области и интерфейс/02 Terminal-first интерфейс.md>), [Нормативные шаблоны](<../UX/01 Нормативные шаблоны интерфейса.md>) | Принято; implementation gap |

## Переданное графовое направление

| Тезис | Фиксация | Состояние |
|---|---|---|
| Документальный и кодовый графы, идентичность узлов, ревизии, семантический слой, межконтурное влияние и графовые запросы переданы FastGraph. | [FastGraph](<../FastGraph.md>), [прежний TDR-FS-1](<../TDR/TDR-FS-1 Graph knowledge plane.md>) | Передано; прежние DT5-DT11 заменены |
| FastSearch поставляет FastGraph только проверяемый снимок допущенных источников и не разделяет с ним хранилище. | [TDR-FS-3](<../TDR/TDR-FS-3 Поставщик снимков источников.md>), [DT12](<../Roadmap/08 DT12 Поставщик снимков для FastGraph.md>) | Принято; будущая реализация |
| Качество поиска и моделей FastSearch квалифицируется отдельно от качества графа FastGraph. | [PAR-FS-010](<../../Paradigms/Архитектура/Сопровождение графа/05 Evidence-first выбор моделей.md>) | Принято |
