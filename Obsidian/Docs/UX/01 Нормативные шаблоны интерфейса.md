# Нормативные шаблоны интерфейса

[← Terminal UX](<00 Terminal UX.md>)

## Назначение

Шаблоны фиксируют информационную и навигационную форму human-interface. Конкретная ширина separator и timestamp вычисляются `terminal-dialogue`; FastSearch не воспроизводит их строковыми литералами.

Обязательный visual contract:

- заголовок преобразуется в uppercase framework policy;
- content имеет единый двухпробельный левый отступ;
- adaptive separator использует framework accent и timestamp;
- selection, prompt, progress, result, empty-state и error создаются типизированными компонентами;
- при `NO_COLOR` структура и читаемость сохраняются;
- на узком terminal содержимое деградирует без потери actions и provenance.

## 1. Выбор рабочей области

```text
FASTSEARCH                                      15:24
══════════════════════════════════════════════════════

  НЕДАВНИЕ ОБЛАСТИ

  1  FastSearch          D:\Igor\Programming\FastSearch
  2  Terminal Dialogue  D:\Igor\Programming\terminal-dialogue
  3  CadFrame            D:\Igor\Programming\CadFrame

  N  Создать рабочую область
  Q  Выйти

  fastsearch › _
```

Если current directory однозначно принадлежит известной области, FastSearch открывает её без picker. Если catalog пуст, показывается empty-state с единственным primary action создания области.

## 2. Создание области и discovery review

```text
НОВАЯ РАБОЧАЯ ОБЛАСТЬ                           15:25
══════════════════════════════════════════════════════

  Корень рабочей области
  root › D:\Projects\Product
```

После bounded discovery:

```text
ОБНАРУЖЕННЫЕ ИСТОЧНИКИ                          15:25
══════════════════════════════════════════════════════

  ДОКУМЕНТАЦИЯ
  ✓ documentation
  ✓ specifications

  КОД
  ✓ backend
  ✓ frontend

  Исключения  .git · .fastsearch · node_modules · target · build

  Enter  Создать область
  E      Изменить источники
  Esc    Назад
```

Каждый contour можно очистить или пропустить. Service path, database path и model path отсутствуют.

## 3. Состояния источников

Ноль contours:

```text
ИСТОЧНИКИ НЕ НАСТРОЕНЫ                          15:26
══════════════════════════════════════════════════════

  FastSearch пока не знает, где искать.

  1  Найти источники автоматически
  2  Добавить документацию
  3  Добавить код
  4  Изменить корень области
```

Один contour:

```text
  Источники    документация · 3 корня
  Код          не подключён
  Индекс       актуален
```

Два contours:

```text
  Источники    документация · код
  Корни        3 документации · 2 кода
  Индекс       актуален
```

## 4. Открытая область и поиск

```text
FASTSEARCH                                      15:27
══════════════════════════════════════════════════════

  Область      Product
  Источники    документация · код
  Индекс       актуален

  fastsearch › где определяется политика retry
```

Bare text запускает search. Глобальный минимальный namespace:

- `/workspace` — сменить или создать область;
- `/sources` — просмотреть и изменить два source contours;
- `/status` — freshness и capabilities;
- `/index` — update/status и advanced rebuild;
- `/help` — contextual help;
- `/exit` — controlled shutdown.

## 5. Видимое обновление индекса

```text
ОБНОВЛЕНИЕ ИНДЕКСА                              15:27
══════════════════════════════════════════════════════

  Документация  готово       214 файлов
  Код           68%          391 / 575 файлов

  Изменено      14
  Добавлено      7
  Удалено        2
```

Initial/update indexing может быть lifecycle action открытия области. Full rebuild остаётся отдельным подтверждаемым maintenance action и не скрывается внутри search request.

## 6. Результаты поиска

```text
РЕЗУЛЬТАТЫ                                      15:28
══════════════════════════════════════════════════════

  Запрос       политика retry
  Найдено      7
  Индекс       актуален

  1  [DOC]  Retry policy
     docs/runtime/retries.md · раздел «Ограничения»
     …повтор выполняется только для transient failure…

  2  [CODE] RetryPolicy::should_retry
     src/runtime/retry.rs
     …классифицирует ошибку и проверяет remaining budget…

  1–7  Открыть результат
  N    Новый поиск
  Esc  Назад
```

Result detail содержит stable ID, source/root label, locator, revision/freshness, channels и доступные local actions. Physical service paths не отображаются.

## 7. Пустой результат

```text
НИЧЕГО НЕ НАЙДЕНО                               15:28
══════════════════════════════════════════════════════

  Запрос       политика повторного подключения
  Область      Product
  Источники    документация · код

  Попробуйте сократить запрос или изменить фильтр.

  Enter  Новый поиск
  F      Фильтры
  Esc    Назад
```

Empty result отличается от unavailable contour и от empty index.

## 8. Ошибка и частичная доступность

```text
ПОИСК ВЫПОЛНЕН ЧАСТИЧНО                         15:29
══════════════════════════════════════════════════════

  Документация  доступна
  Код           недоступен · индекс повреждён
  Векторный     не настроен

  Показаны результаты из доступных каналов.

  1  Показать результаты
  2  Восстановить индекс кода
  Esc Назад
```

Framework error document показывает code, message, recovery actions и optional technical detail; panic/debug dump не является пользовательским экраном.

## 9. Маршрутизация

```text
FASTSEARCH
├── Рабочие области
│   ├── продолжить
│   ├── выбрать
│   ├── создать
│   └── удалить только из глобального списка
│
└── Открытая область
    ├── поиск
    │   └── результаты
    │       ├── открыть
    │       ├── показать фрагмент
    │       ├── связанные материалы
    │       └── новый поиск
    ├── источники
    │   ├── documentation roots
    │   ├── code roots
    │   ├── discovery
    │   └── exclusions
    ├── индекс
    │   ├── состояние
    │   ├── обновить
    │   └── перестроить
    ├── capabilities
    │   └── optional providers
    ├── сравнение моделей
    │   ├── готовность model indexes
    │   ├── обновить stale/absent
    │   ├── единый запрос
    │   ├── разделённые результаты
    │   └── вернуться без смены active model
    └── сменить область
```

## 10. Режим сравнения моделей

Режим открывается явной командой `/compare` и не становится состоянием обычного поиска. Первый экран проверяет весь admitted catalog:

Каталог `/model` и readiness `/compare` используют `TableDocument`. На широком terminal значения читаются по единым колонкам; на узком framework переключает весь документ в вертикальные подписанные строки. `\t`, ручной padding и смешивание table-row с произвольными detail-lines в FastSearch запрещены. Длинные source URL/revision вынесены в `/model info <номер|slug>`.

Несколько доступных действий никогда не склеиваются в одну строку. FastSearch
передаёт их как отдельные `ActionItem` внутри `NextStep`, а
`terminal-dialogue` выводит команды вертикально в стабильном порядке. Это
правило действует для workspace status, model/source screens, результатов,
comparison mode и шагов discovery.

Экран `/sources` явно сообщает, что это просмотр, а не вложенный режим. Он
объясняет назначение `-`, показывает переход к workspace summary, общую
справку и выход из приложения. Пользовательские пути нормализуются под текущую
ОС; Windows-префиксы `\\?\` и смесь `/` с `\` в одном экране запрещены.

```text
СРАВНЕНИЕ МОДЕЛЕЙ                              15:31
══════════════════════════════════════════════════════

  МОДЕЛЬ                 ИНДЕКС           РАЗМЕР      ПОСТРОЕНИЕ
  E5 Small               готов             72.4 MiB       41 с
  E5 Base                готов            139.8 MiB   1 мин 18 с
  E5 Large               не готов         211.2 MiB   2 мин 49 с
  Qwen3 0.6B             не готов                  —            —
  Nomic v2 MoE           готов            142.1 MiB   1 мин 31 с

  /update  Обновить требуемые индексы после preview
  текст    Сравнить все готовые модели
  /back    Вернуться к обычному поиску
```

После подтверждённого update либо при полной готовности появляется один query prompt. Результаты идут вертикальными блоками: эта форма остаётся читаемой на узком terminal и не создаёт ложное межмодельное ранжирование.

Во время update readiness-таблица сменяется одной live-region. Строки не
добавляются вниз при каждом событии: framework перерисовывает прежний кадр.
Каждая модель остаётся видимой от ожидания до результата; determinate progress
показывается полосой и фактическим счётчиком без процента. Этапы без точного
внутреннего счётчика показывают lifecycle stage и этапную полосу, не выдуманный
процент. При redirect/CI каждый снимок дописывается обычным текстом без ANSI.

```text
ПОДГОТОВКА СРАВНЕНИЯ — ВЫПОЛНЯЕТСЯ
  Завершено: 2 из 6 задач.

  ✓ Общий корпус и лексический индекс — готово
    [████████████████████████████████] 3 / 3 этапов
  ▶ E5 Small — построение модельного индекса
    [████████████████░░░░░░░░░░░░░░░░] 1 / 2 этапов
  ○ E5 Base — ожидает
    [░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░] 0 / 2 этапов
```

```text
СРАВНЕНИЕ РЕЗУЛЬТАТОВ                          15:38
══════════════════════════════════════════════════════

  Запрос       политика retry
  Корпус       generation 42 · 18 240 записей
  Top-K        5

  LEXICAL BASELINE
  L1  Retry policy
      docs/runtime/retries.md

  A · E5 SMALL · 384D                            84 ms
  A1  Retry policy
      docs/runtime/retries.md
  A2  RetryPolicy::should_retry
      src/runtime/retry.rs

  B · E5 BASE · 768D                            131 ms
  B1  RetryPolicy::should_retry
      src/runtime/retry.rs
  B2  Retry policy
      docs/runtime/retries.md

  C · QWEN3 0.6B · 1024D                       ошибка
      Runtime недоступен; остальные модели показаны.

  /open A1  Открыть результат
  текст     Новый единый запрос
  /status   Повторить readiness check
  /back     Завершить сравнение
```

Raw scores между блоками не показываются как сопоставимые. Active model обычного режима отображается в status context, но `/compare` её не изменяет.

## 11. Проверяемый contract

Implementation считается соответствующей шаблонам, когда golden tests покрывают picker, create/discovery, 0/1/2 contours, current/stale/partial index, results, empty result, recoverable error, comparison readiness matrix, update confirmation, model blocks, partial comparison, narrow terminal и `NO_COLOR`; transition tests доказывают back/cancel/exit из каждого состояния; boundary test запрещает FastSearch application code вручную печатать ANSI, separator, timestamp и framework indentation.
