# Межграфовая трассируемость

Парадигма передана FastGraph и заменена его межконтурной трассируемостью и этапами FG4 и FG7. [Карта передачи](<../../../Docs/FastGraph.md>) содержит целевые источники.

[← Графы знаний](<00 Графы знаний.md>)

## Статус

Принято связывать document и code namespaces; semantic matches являются candidates до проверки.

## Контекст

Изменение TDR должно показывать потенциально затронутый код, а изменение кода — документы и contracts, которые могут устареть. Ручные CFMap-ссылки дают полезный beacon, но не масштабируются как отдельный файл на каждую область.

## Парадигма

FastSearch хранит document и code nodes в одном типизированном knowledge graph и связывает namespaces edges `DOCUMENTS`, `GOVERNED_BY`, `DECIDED_BY`, `IMPLEMENTS`, `VERIFIED_BY`, `CONTRADICTS`. Explicit stable IDs и authored links создают high-confidence relations; semantic search по node descriptions создаёт ranked candidates, которые graph curator принимает, отклоняет или уточняет.

## Границы

- Similarity не становится verified edge автоматически.
- CFMap `@related` импортируется как explicit candidate/verified relation по migration policy, но CFMap не остаётся обязательным authoring format.
- Изменение documentation создаёт impact candidates, но не меняет code state.
- Изменение code graph создаёт stale/review queue для semantic links, но не переписывает TDR.
- Dtree запускает curator; FastSearch хранит graph and candidates.

## Инварианты

- Edge содержит origin, confidence, verification state, source/target revisions и curator provenance.
- Candidate и verified relation доступны разными filters.
- Accepted link переносится через `.fastsearch/knowledge/curated` и не зависит от одной локальной SQLite.
- Superseded document link не молча переезжает на новый source без rule или review.
- Impact query объясняет root cause и traversal path.

## Связь с реализацией

CanonicalRecord уже поддерживает relations, а `.cfmap.md` — explicit `@related`, но общего document/code graph, candidate lifecycle и verified portable cross-links нет.
