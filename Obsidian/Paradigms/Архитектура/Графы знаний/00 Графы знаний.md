# Графы знаний

[← Архитектура](<../00 Архитектура.md>)

## Назначение

Раздел определяет один типизированный knowledge graph с двумя связанными namespaces — `documentation` и `code` — и доступ человека/agents к нему. Каждый namespace объединяет несколько admitted roots своего contour, не смешивая analyzer rules и provenance.

## Порядок чтения

1. [Документальный граф](<01 Документальный граф.md>) — authored knowledge и authority.
2. [Иерархический граф кода](<02 Иерархический граф кода.md>) — modules, classes, functions и language relations.
3. [Межграфовая трассируемость](<03 Межграфовая трассируемость.md>) — documentation ↔ code links и impact.
4. [Полный граф через ограниченные запросы](<04 Полный граф через ограниченные запросы.md>) — initial slice и свободное расширение.
