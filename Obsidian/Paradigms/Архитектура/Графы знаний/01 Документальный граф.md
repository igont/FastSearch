# Документальный граф

Парадигма передана FastGraph и заменена его предметной моделью и этапом FG4. [Карта передачи](<../../../Docs/FastGraph.md>) содержит целевые источники.

[← Графы знаний](<00 Графы знаний.md>)

## Статус

Принято развитие текущего document record index в типизированный graph. Русский authored corpus и английские технические термины являются обязательным quality profile.

## Контекст

Отдельный section hit недостаточен для ответа, какой документ является package, механизмом, заменой, нормативным источником или строкой производного реестра. Authority и hierarchy нельзя выводить только из vector score.

## Парадигма

FastSearch строит document namespace единого knowledge graph с nodes root/corpus/document/section/paradigm/TDR/roadmap/contract/registry row/decision/evidence и typed relations `CONTAINS`, `REFERENCES`, `SUPERSEDES`, `IMPLEMENTS`, `DERIVED_FROM`, `EVIDENCES`, `CONFLICTS_WITH`. Ноль или несколько document roots проходят один document analyzer contract и объединяются без потери `root_id`.

## Границы

- Authored text остаётся source of truth; graph хранит locator, hash и revision.
- Explicit IDs и links имеют более высокую authority, чем semantic similarity.
- Generated registry row не получает нормативность исходного paradigm/TDR.
- Vector model помогает найти кандидатов, но не определяет supersession или acceptance.
- Partial parser coverage помечается и не выдаётся за полный corpus.

## Инварианты

- Node сохраняет source kind, authority class, locator, content hash и document revision.
- Один document может участвовать в нескольких typed relations без копирования текста.
- Broken link, duplicate stable ID и conflicting supersession наблюдаемы.
- Exact technical identifier не ухудшается после semantic enrichment.
- Rebuild не меняет accepted authored IDs из-за форматирования.
- Одинаковый relative locator в разных document roots различается stable `root_id`.

## Связь с реализацией

DT2/DT3 умеют парсить Markdown, frontmatter, sections и TSV rows и искать их exact/FTS/vector. Typed document hierarchy, supersession graph и authority-aware traversal отсутствуют.
