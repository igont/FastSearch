# Ревизии рёбер и причинная актуальность

Парадигма передана FastGraph и заменена его контрактом ревизий и этапом FG5. [Карта передачи](<../../../Docs/FastGraph.md>) содержит целевые источники.

[← Сопровождение графа](<00 Сопровождение графа.md>)

## Статус

Принята versioned модель graph facts и semantic freshness. Состояние изменения хранится прежде всего на directed edges и причинных events; node summary вычисляется автоматически.

## Контекст

Один флаг `stale` смешивает удалённый call, новый relation, локально обновлённую реализацию и действительно нарушенный contract. Физическое проставление stale на тысячах downstream edges создаёт шум и дорогой curator queue.

## Парадигма

FastSearch хранит immutable observed graph revisions и accepted semantic baselines. Edge имеет независимые dimensions:

- presence: `present | removed`;
- delta: `unchanged | added | removed | metadata_changed`;
- semantic state: `current | updated | stale | unverified`;
- confidence: `exact | inferred | reviewed`;
- cause: change event, root node и revision.

UI категории «новое», «актуальное», «обновлённое», «устаревшее», «удалённое» выводятся из этих dimensions. Node summary подсчитывает incident edges и root causes, но не дублирует их вручную.

## Классы воздействия

- L0 — formatting/comments/declaration order: graph semantics не меняется.
- L1 — implementation update при сохранённом contract: root `updated`, каскад не создаётся.
- L2 — behavior/side effects: direct semantic relations требуют review.
- L3 — signature/contract/invariant: affected incoming/outgoing boundaries становятся stale candidates.
- L4 — module ownership/architecture: propagation до document/TDR boundaries.

## Причинная invalidation

Каскад хранится как root `ChangeEvent` и правило propagation, а не как тысячи независимых записей. Curator verdict `local_only`, `bounded_to`, `propagate_to_callers` или `architectural_review_required` закрывает либо уточняет derived affected set. Cycles обрабатываются через strongly connected components.

## Инварианты

- Structural relation current revision не называется stale fact: удаление и добавление отражаются delta.
- Root fix может закрыть derived cascade только при явном scope verdict.
- Contract change не лечит downstream автоматически без evidence.
- Accepted baseline продвигается review commit транзакционно для выбранных nodes/edges.
- История revisions и removed tombstones сохраняется согласно retention policy.
