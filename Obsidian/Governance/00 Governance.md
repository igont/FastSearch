# Governance

[← Главная навигация](<../00 Навигация.md>)

## Назначение

Governance задаёт формат локальной библиотеки FastSearch и намеренно не переносит CadFrame gates, Status Vector и capability registries.

## Действующие правила

1. [Статусы и стадии реализации](<01 Статусы и стадии реализации.md>)
2. [Правила парадигм](<02 Правила парадигм.md>)
3. [Правила TDR](<03 Правила TDR.md>)
4. [Шаблоны](<Templates/00 Шаблоны.md>)

## Намеренно исключено

- отдельные шкалы coherence/evidence/alignment;
- gates и approvals, не используемые runtime roadmap FastSearch;
- дублирование implementation evidence в парадигмах;
- обязательное превращение Markdown в generated database dump.

Новая ось управления добавляется только после отдельного решения и реальной потребности.
