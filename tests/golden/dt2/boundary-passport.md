# A1 boundary passport for MG-A2

- Identity: `StableId = source kind + normalized repo-relative locator + record-local component`. The locator never uses an absolute path, SQLite rowid, or Tantivy document id. Markdown uses its normalized heading path; TSV uses its one-based row. Rename creates a new ID, delete removes the old ID, and a duplicate StableId is a typed failure rather than silent overwrite.
- Hashes: file hash is computed from the source bytes after UTF-8 BOM removal and newline normalization, scoped to the whole source file and tagged with parser version. record hash is computed from normalized `CanonicalRecord` source facts: kind, locator, title, searchable content, raw metadata and relations; it excludes storage/index projection fields and is also parser-version tagged. file hash detects source change; record hash decides logical record mutation.
- Canonical boundary: `CanonicalRecord` keeps source facts, raw metadata and relations only. Tantivy analyzer, schema, ranking weights and projection generation do not leak into it.
- Lifecycle/status: SQLite is the accepted durable authority only after its transaction commits the complete record/hash change set. `current` means SQLite record hash and accepted Tantivy generation agree; `stale` means SQLite is authoritative but its lexical projection is behind or absent; `degraded` means the last projection attempt failed and the prior durable authority remains recoverable. A failed projection never marks stale output current. `search` on stale must surface stale status with its result; `status` reports the three states; `update` persists the authority before requesting projection; `rebuild` recreates the disposable projection and makes it current only after accepted generation. These outcomes survive a new process reopen.
- Public surface: current CRUD and Available/Unavailable are insufficient unless A2 proves them capable of expressing the accepted lifecycle/status outcomes. Every gap is classified test-only, adapter-only, or public contract; only public contract gaps open A2 product changes.
- Composition: E calls accepted public ports only and does not reach SQLite transactions or Tantivy writers directly. A new public method or cross-store authority is A backflow and material replan.
- Ranking: exact dominates lexical. Current/Design modifiers remain D-owned. The final equal-score tie-break is lexicographic StableId ascending; it never depends on traversal or index insertion order.
