# Лицензии и доставка артефактов A2

Проверенные зависимости и модель допускают выбранный способ использования. Qwen3-Reranker-0.6B и `rmcp 3.1.4` распространяются по Apache-2.0. Candle 0.11.0 имеет двойную лицензию MIT или Apache-2.0, `tokenizers 0.22.2` - Apache-2.0. Их условия допускают локальное выполнение и распространение производного исполняемого файла с сохранением обязательных уведомлений.

Веса Qwen доставляются отдельно во внешний машинный кэш по репозиторию и неизменяемой редакции из `model-manifest.json`. Git содержит только идентичность, контрольные суммы и код загрузки. Файл `model.safetensors` размером 1 191 588 280 байт не входит в исходники, ресурсы сборки или исполняемый файл. Проверка выпуска сопоставляет размеры, проверяет список файлов Git и ищет в исполняемом файле контрольную сумму весов. Само имя `model.safetensors` может присутствовать как имя ожидаемого внешнего файла и не означает встраивание его содержимого.

Источники проверки: метаданные `cargo info candle-transformers@0.11.0`, `cargo info rmcp@3.1.4`, `cargo info tokenizers@0.22.2` и поле `license: apache-2.0` официальной карточки Qwen закреплённой редакции. Перед публичным выпуском полный набор уведомлений должен быть собран из точного `Cargo.lock`; A2 подтверждает совместимость лицензий, но не выполняет выпуск.
